# Kai-custom

> FOSS fork of [Kai](https://github.com/SimonSchubert/Kai) — an open-source AI assistant with persistent memory, Telegram integration, and persona system.

An AI assistant that remembers you, runs on-device or via 25+ API providers, and can control phone features through text or voice. Fully open-source, zero telemetry.

## Features

### Persistent Memory (Two-Tier)

Local semantic memory with automatic extraction across conversations:

- **User memories** — facts, preferences, entities extracted inline every 5 exchanges (AutoMemoryLearner), deletable in UI
- **Behavior memories** — patterns extracted post-heartbeat, stored as **protected** (HeartbeatMemoryExtractor), hidden from deletion UI
- **Soul split** — `soul_user` (editable in Settings) + `soul_auto` (auto-generated by heartbeat), combined in system prompt
- **Persona system** — named personas with configurable name/description/soul defaults (Kai, ALT built-in)
- **Memory toggle** — disables memory/KG/diary tools and extraction when off

### Telegram Bot Integration

Chat with the AI via Telegram:

- **Auto-polling** — receives messages every ~10s, processes via `askSilently()` for near-real-time replies
- **Authorized chat IDs** — allowlist prevents unauthorized users
- **Tools** — `check_telegram` (history), `send_telegram_message` (send messages)
- **Settings UI** — bot token input, authorized IDs, enable switch, test connection, Experimental badge

### 25+ LLM Providers

Multi-service with automatic failover: Anthropic · OpenAI · Gemini · DeepSeek · Mistral · xAI · OpenRouter · Groq · NVIDIA · Cerebras · Ollama Cloud · Together AI · HuggingFace · Venice AI · Moonshot AI · Z.AI · MiniMax · AIHubMix · Deep Infra · Fireworks AI · OpenCode · PublicAI · OpenAI-Compatible · LiteRT On-Device · Free tier

### On-Device Inference

Run AI models locally via LiteRT: Qwen3 0.6B · Gemma 4 E2B IT · Gemma 4 E4B IT. Models download from HuggingFace on first use.

### Phone Tools (Android)

8 individually toggleable tools: GPS location, Contacts, Device info, Battery status, Network info, WiFi details, Clipboard, Installed apps. Permission-gated at runtime.

### SSH Remote Execution

Multi-profile SSH with JSch: `ssh_connect`, `ssh_disconnect`, `ssh_execute_command` tools. Interactive terminal with live transcript. Persistent sessions across commands.

### Linux Sandbox

Alpine Linux via proot, no root required. Shell execution, file read/write/delete, binary file write. Interactive terminal alongside AI.

### MCP Server Support

Streamable HTTP MCP: Fetch, DeepWiki, Sequential Thinking, Context7, Globalping, CoinGecko, Manifold Markets, Find-A-Domain. Add custom endpoints in Settings.

### Heartbeat

Autonomous 30-minute self-checks (configurable, 8am–10pm). Reviews memories, tasks, emails, SMS. Surfaces in-app notifications when needed.

### Task Scheduler

Cron and one-shot tasks with exponential backoff. Execution log.

### Dynamic UI (kai-ui)

Generate interactive screens — quizzes, dashboards, forms, brainstorms — with buttons, inputs, lists, real-time state.

### Wake Word ("Hey Kai")

Experimental dual-mode detection: GENERAL (TFLite on-device) + PERSONAL (cosine similarity enrollment). Adaptive energy baseline, anti-flap, trigger debounce, mic handover.

### Voice & TTS

Speech-to-text via Android SpeechRecognizer. Text-to-speech via edge-tts (27 languages), `speak_text` tool.

## Quick Start

```bash
# Build debug
.\gradlew.bat :androidApp:assembleFossDebug

# Install on device
adb install -r androidApp\build\outputs\apk\foss\debug\androidApp-foss-arm64-v8a-debug.apk

# Build release (needs signing config)
.\gradlew.bat :androidApp:assembleFossRelease
```

## Build Dependencies

- Android SDK 34+, JDK 21+
- No Google Play Services, no Firebase, no proprietary SDKs
- Targets: Android (primary), Desktop (JVM), WasmJs, iOS

## CI / Releases

Tag pushes (`v*`) trigger automated builds via GitHub Actions:
- APK is built, signed, and published as a GitHub Release
- Desktop packaging (DMG/MSI/DEB/RPM/AppImage) runs on best-effort basis
